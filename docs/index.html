Data Dictionary

About this resource

Scope — 609 fungal biosynthetic gene-cluster dossiers, each linked to a MIBiG accession.

Data organization — Separate tables contain BGCs, organisms, strains, facets, genes, metabolites, experiments, experimental terms, measurements, observations, claims, relationships, conflicts, sources and evidence links.

Source traceability — SOURCE and EVIDENCE_LINK contain literature and database provenance.

Raw data — RAW_ROW retains non-empty biological source rows.

Normalization — TERM contains raw and canonical term labels; NORMALIZATION_QUEUE contains mappings that remain unresolved.

Missing or uncertain values — Explicit missingness and uncertainty states are retained where present.

Snapshot — Static shareable copy created 21 August 2026. The working normalization file remains separate.
